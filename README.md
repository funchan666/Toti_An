# Toti for Android

Flutter Android application based on the LookMe iOS A-side. Original project media, fonts, sample profiles and editorial content are included. The B-side routing, WebSocket and remote WebView integration are excluded. The Android application ID is `com.toticonnect.meetcommunity`; configure release signing before publishing.

## Current functionality

The five main areas include short videos, discovery, example rooms, messages and profile. The app includes follows and sample incoming followers, comments and local safety tools; room filters, member lists, local microphone capture and example gift selection; local camera capture and call/broadcast previews; pending submissions; profile editing, daily coins, effects and backpack. English, Chinese, Spanish, Japanese and German translation dictionaries are imported from LookMe; strings not present in those dictionaries still appear in English.

Editorial profiles, videos, room cards and comments have been imported to the Toti Supabase project. The app source reads them from the project, with bundled content and media retained as a transitional fallback. Real-account follow, block, direct-message, comment, like and report code uses Supabase; these flows have not been run or verified. Interactions with example profiles and room gifts remain previews. Microphone and camera previews are not broadcasts or connected calls. Submissions remain pending. Profile text, selected avatars, comments and likes are wired to Supabase; room activity, wallet state and other attachments remain on the device. The account deletion function is deployed and wired in source but has not been exercised.

## Outstanding

This is not yet a complete or visually verified one-to-one port or a complete Tods A integration. The source now uses Supabase email/password authentication and separate account-scoped device state. Email confirmation is enabled, and Brevo SMTP and the confirmation redirect have been configured; email delivery and the redirect have not yet been verified. Existing pre-account device state is preserved and is set to migrate to the first successfully signed-in email account, subject to runtime verification. Realtime messaging, avatar upload, reports and account deletion have not been verified. A moderation operating process, complete cloud migration and actual live audio/video remain unfinished. Some room and activity details, speaker routing, complete translation coverage, and the exact original visual treatment still differ. Toti's Google Play checkout is disabled until real product configuration, transaction verification, fulfillment and recovery exist. See `docs/GOOGLE_PLAY_PRODUCTS.md` for proposed IDs and reference prices.

The policy drafts remain in the repository and Google Drive, but are not bundled into the app. Both policy screens load public HTTPS pages in a WebView: `https://toti-terms-privacy.aqua-fly-0681.chatgpt.site/terms` and `https://toti-terms-privacy.aqua-fly-0681.chatgpt.site/privacy`. These defaults may be overridden at build time using `--dart-define=TOTI_TERMS_URL=https://...` and `--dart-define=TOTI_PRIVACY_URL=https://...`. The published pages are separate copies, not automatically synchronized with the Google Drive drafts. The pages are review drafts; before release, establish a privacy contact and update them to match the final features, services and data practices. The currently observed Play developer account was removed and cannot publish apps.

Before the UI refinement, an Android ARM64 debug APK was built and run on an Android 14 emulator. Login, video display, room entry and a local room message, and the daily coin reward were checked on the emulator; eight Flutter tests passed. The UI refinement and current Supabase changes have not yet been built or run. The app requires Android 7.0 (API 24) or later. A physical device, pixel-by-pixel comparison, release build, Google Play purchase, camera and microphone capture, and live services were not verified.
